About This Appointment Scheduler

This system manages patient appointments with an HTML/CSS/JavaScript frontend and a PHP + MySQL backend.

System Features

  • Book new patient appointments
  • View scheduled appointments
  • Edit appointment details
  • Delete appointments
  • Automatic database and table creation
